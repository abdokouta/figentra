# Figentra

## Company Definition & Corporate Positioning

**Status:** CANONICAL / APPROVED
**Date:** 2026-09-04

## 1. Who is Figentra?

**Figentra is an agentic development company building AI-native software platforms and applications for MENA and global markets.**

Figentra is headquartered in the UAE and is positioned to serve the broader Middle East and North Africa region while building for customers and opportunities globally.

Figentra combines agentic software development, enterprise platform engineering, and product development into one technology company.

The company creates reusable technology, builds complete digital products, and develops an ecosystem around those products.

## 2. What does Figentra do?

Figentra builds software using AI agents as a core part of the engineering lifecycle.

The company focuses on:

- Agentic software development
- Enterprise technology platforms
- AI-native applications
- Cloud and distributed systems
- Developer infrastructure
- Digital products
- Enterprise automation
- AI-enabled business systems

The objective is not simply to make developers write code faster. The objective is to change how complete software systems are conceived, engineered, tested, deployed, and operated.

## 3. What does Figentra offer?

Figentra's offering has two primary technology products and an expanding application portfolio.

### Technology products

1. **Figentra Agentic Development** — AI-native software development platform.
2. **Figentra OS** — Enterprise Operating System.

### Application products

1. **Academorix** — sports-academy SaaS application.
2. **Beautilon** — Figentra application; current product name.
3. Future products and vertical applications.

## 4. The Figentra thesis

Software is moving from a model where humans manually implement most of the system to a model where humans direct increasingly capable agents that execute large portions of the software lifecycle.

Figentra is building for that transition.

The company believes the winning architecture combines:

```text
Human direction
      +
AI-agent execution
      +
Enterprise governance
      +
Reusable platform infrastructure
      +
Production-grade engineering
```

## 6. Figentra Agentic Development

The company's AI-native development platform coordinates specialized agents across product definition, architecture, implementation, testing, security, deployment, and operations.

It is the company's **software creation engine**.

See `docs/figentra-agentic-development.md`.

## 7. Figentra OS

Figentra OS is the company's enterprise operating platform.

It provides common infrastructure and enterprise services for applications, products, and organizations.

It is the company's **software operating foundation**.

See `docs/figentra-os.md`.

## 8. Applications

Applications demonstrate what can be built using the Figentra ecosystem.

### Academorix

**Academorix is a sports-academy SaaS application.** Its current V1 scope is centered on the core academy operating workflow: tenant creation, authentication, user invitations, branches, teams, and tenant-scoped management for coaches, athletes, and parents.

Its product-specific business logic and data remain application-owned.

### Beautilon

**Beautilon** is an application product built by Figentra.

The current canonical name is **Beautilon**. The former name **Beauty Loan** is retained only as historical naming context.

## 11. What makes Figentra different?

Figentra combines three normally separate activities:

1. Building the AI system that changes how software is developed.
2. Building the enterprise platform that software operates on.
3. Building real applications that prove the technology in production.

This creates a closed technology-to-product loop:

```text
Agentic Development
        ↓
Build Products
        ↓
Run on Figentra OS
        ↓
Learn from Production
        ↓
Improve Platform + Agents
        ↓
Build Better Products
```
