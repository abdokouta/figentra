# Generic Agent Tool Adapter

Any future AI coding tool is accepted only as an adapter to the Figentra Engineering System.

## Minimum capabilities

A conforming tool should be able to consume, directly or through generated projections:

1. universal repository instructions;
2. persistent engineering rules;
3. specialist agent definitions;
4. on-demand skills/procedures;
5. structured planning artifacts;
6. deterministic validation hooks where supported;
7. permission/approval boundaries;
8. provenance and evidence outputs.

## Required behavior

The adapter must preserve:

- source-of-truth hierarchy;
- ownership boundaries;
- agent authority;
- routing decisions;
- artifact traceability;
- security policy;
- production quality gates.

A tool that cannot represent a feature directly should use a thin reference document or generated projection rather than inventing a second policy system.
