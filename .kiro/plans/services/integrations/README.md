# Integrations Service Plan

Canonical production plan set: architecture, implementation, API, PostgreSQL data model, NATS/events, jobs/scheduling, security/authorization, observability, testing, and deployment/operations.

Integrations owns external business-system connectivity: provider adapters, tenant connections, credential references, webhooks, outbound requests, sync, mappings and reconciliation. Authentication providers such as Supabase/Clerk remain Identity-owned.
