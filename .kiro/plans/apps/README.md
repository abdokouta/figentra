# Application Plans

Application plans describe product-facing compositions. Apps own UX/product composition and consume services through public APIs/events/contracts; they do not import service implementations or redefine platform contracts.

Apps may use reusable SDK packages such as `@stackra/identity` and `@stackra/tracking` where applicable. Domain/business rules remain server-side in their owning services.

Current Kiro application specifications: Portal, Family, Landing Page, and Mobile Application Standard.
