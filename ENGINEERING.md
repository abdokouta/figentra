# Figentra Engineering System

This repository uses the **Figentra Agent Engineering System** as its tool-neutral software-development operating model.

Start here for agentic engineering work:

1. `AGENTS.md`
2. `docs/engineering-system/README.md`
3. `docs/engineering-system/constitution.md`
4. `docs/engineering-system/sdlc.md`
5. `docs/engineering-system/routing.md`
6. `.kiro/specs/figentra-platform/ARCHITECTURE.md`
7. the relevant `.kiro/plans/**` contract

Kiro, Cline and other coding agents are adapters to this system. Their local rules, steering files, skills and agent definitions must not become competing sources of truth.

For a new change: classify → discover → specify → decide → plan → build → verify → review → release → operate → learn.
