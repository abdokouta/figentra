# V2 Phase 0 — Architecture Gate

This phase must be completed before implementation work begins.

## Required output

- Accepted ADRs under `docs/adr/`.
- Accepted engineering standards under `docs/standards/`.
- V2 task list with status tracking.
- No unresolved architecture conflict between ADRs.
- No implementation task may silently override an accepted ADR.
