# Service Security Checklist

- [ ] Service principal exists
- [ ] Service authentication implemented
- [ ] Audience validation
- [ ] Token expiry validation
- [ ] Authorization check
- [ ] Least privilege
- [ ] Secrets externalized
- [ ] Secret rotation
- [ ] Request IDs
- [ ] Audit requirements
- [ ] No sensitive logging
- [ ] Rate limits
- [ ] Idempotency
- [ ] Replay protection where relevant
- [ ] Security tests
