Jersey typography · v1.1

Three families. One system. Pick per academy.

Every Academorix academy picks one numeral family and uses it end-to-end — jerseys, rosters, trophies, roster boards, scoreboards. The workspace default is Modern (Geist 800) because it's already the type language of every product screen; the other two are legitimate swap-outs when the academy's visual voice calls for them.
