Season mark

Coin-stamp mark for a season. Ships on kit tags, session cards, roster boards.

ALL CAPS · mono orbit
2 – 3 words · uppercase display
Format · YYYY / YY
Optional · leave blank for a generic season mark

Anatomy

  1. Outer double ring — ink hairlines + 12-tick minute marks; top tick painted Track Orange.
  2. Top arc — academy name in Geist Mono, letter-spacing 0.24em.
  3. Bottom arc — season + year in Geist Mono at 72% opacity.
  4. A-Chevron mark — 1.2× default scale, ink strokes, Track Orange apex marker.
  5. Season plate — Track Orange band with the season name centred.
  6. Discipline tag — mono caption at 62% opacity.
  7. Chevron cluster — 3 chevrons descending in opacity, decorative footer.
  8. Provenance stamp — "RECORDED · ACADEMORIX" mono at 50% opacity.

Tournament crest

Shield crest with the tournament title on a Track Orange plate. Ships on programme covers, match reports, medal ribbons.

2 – 4 words · display · ALL CAPS looks best
Roman-numeral + year · e.g. "IX · 2026"
Mono line · reads "HOSTED · ..."
Arc top · mono
Footer mono · dot-separated

Anatomy

  1. Shield outline — ink 4px stroke, inset hairline at 42% opacity.
  2. Track Orange rank pin — top of the shield · echoes the A-Chevron apex marker.
  3. Chevron rank stack — 3 chevrons descending in weight + opacity through the shield face.
  4. Top arc — host city / country in Geist Mono at 72%.
  5. Title plate — Track Orange band with the tournament title, ink chevron tick-marks at each edge.
  6. Edition — Roman-numeral + year in Geist Mono, weight 600.
  7. Host academy — mono line · "HOSTED · ..." at 62%.
  8. Discipline row — dot-separated mono at 72%.
  9. Provenance stamp — small A-Chevron mark + "RECORDED · ACADEMORIX".
