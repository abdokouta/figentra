# Figentra Docs

Canonical documentation and brand operating system for **Figentra Technologies LLC** and its product portfolio.

## Portfolio

```text
Figentra Technologies LLC
│
├── Figentra
│   └── AI agents development company / enterprise technology
│
├── Academorix
│   └── Sports clubs, academies, schools and sports organizations
│
└── Beautilon
    └── Health, care, beauty and wellness organizations
```

## Documentation hierarchy

1. Company Charter — who Figentra is and how the company operates.
2. Brand Charter — how each brand is positioned and expressed.
3. Website Specification — navigation, page architecture, content, layout and conversion.
4. Content System — reusable messaging, CTA, SEO and trust patterns.
5. Visual System — logo, typography, color, icons, imagery, illustration and motion.
6. Asset Registry — canonical files, dimensions and usage rules.

## Rules

- Figentra is the corporate/technology brand.
- Academorix and Beautilon are first-class product brands.
- Each product has its own visual language and UX; there is no one-size-fits-all product template.
- Shared technology does not imply shared visual identity.
- No unsupported customer, revenue, headcount, uptime or market claim may be published.
- Public people profiles require approved names, photos and biographies.
- Product claims must be traceable to product documentation or verified evidence.
- Accessibility target: WCAG 2.2 AA.
- SEO, structured metadata, legal links, security disclosure and consent surfaces are production requirements.
- Marketing content and technical documentation are separate systems.
