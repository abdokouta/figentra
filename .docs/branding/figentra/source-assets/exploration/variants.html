§01 · The signal

Three ways to encode "live in production"

The dot pulses. The cursor blinks. The bicolor cap does neither — it encodes the signal into the letterform itself. Same F glyph underneath all three; only the top-right terminator changes. Every variant reads at 16 px favicon size and inverts cleanly on dark surfaces.

F-Dot · pulsing heartbeat current
Signal-mint dot at the top-right, 1.4 s heartbeat cycle (scale 1 → 1.28, opacity 1 → 0.65). Reads: live / running / on air. Ties directly to the deploy-pulse animation in the footer.
F-Cursor · IDE blink
Signal-mint underscore where the dot was. Steps-based blink (1 s cycle, 50/50 on/off) — same rhythm as a real terminal cursor. Reads: command line / engineering / ready for input. Native to Figentra's developer-tools DNA.
F-Bicolor · monolithic terminator
No separate indicator — the top stroke terminates in a slightly-taller mint block that reads as a seal / stamp / audit cap. Static (or very subtle 3 s glow). Best legibility at 16 px favicon size — the mint block survives rasterization better than a 1-pixel dot.

§05 · My read

Ranked recommendation

Rank Combination Reads as Confidence
1st F-Dot × Inter Display 500 Live / running / governed engineering. The Stripe / Anthropic / Vanta pocket. Nobody scrolls past it wondering what kind of company you are. High — 100% within brand doc
2nd F-Cursor × Geist Sans 500 Command-line / on-the-modern-stack / developer-native. Reads more distinctly as a 2026-current tech company. Slightly narrower audience — developer-adjacent CTOs love it, traditional CTOs find it a hair too edgy. Medium-high
3rd F-Bicolor × IBM Plex Sans 500 Sealed / signed / corporate-serious. Best print + favicon legibility of any combination. Wins with traditional enterprise buyers; the IBM Plex baggage cuts both ways (some read it as "trusted incumbent," some as "IBM clone"). Medium

The strategic question — every one of these is a statement about who Figentra is. F-Dot × Inter says we're the reference implementation. F-Cursor × Geist says we're the modern tech company you should be. F-Bicolor × IBM Plex says we're the trusted engineering partner you can hire. Same product underneath. Very different first impressions.

My call: ship F-Dot × Inter as the default (Pick 1). It carries the widest audience without pinning you to any niche. If your enterprise-sales team explicitly asks for gravitas · trust · corporate-serious, Pick 3. If the founder instinct is let's look like a 2026 tech company, not a 2020 one, Pick 2. Only ship one — the decision cascades to every downstream artefact.
