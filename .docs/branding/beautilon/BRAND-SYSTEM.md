# Beautilon — Visual Brand System v1.0

## Brand idea

Beautilon should feel like a premium operating platform for businesses where care and customer experience matter.

**Design principle:** calm precision.

## Recommended token foundation

| Token | Value | Use |
|---|---|---|
| Ink | `#1D1B1A` | Primary text |
| Paper | `#FAF8F5` | Primary background |
| Surface | `#F1ECE6` | Cards/sections |
| Accent | `#B86B78` | Primary action / emphasis |
| Accent-soft | `#E8C8CE` | Soft emphasis |
| Success | `#2F7D68` | Success |
| Warning | `#B7791F` | Warning |
| Critical | `#B74747` | Error |

These are proposed production tokens and must pass contrast testing before implementation.

## Typography

Recommended:
- Display: Geist or a refined approved display face if licensing/technical constraints permit.
- UI/body: Geist.
- Data/code: Geist Mono.

Avoid mixing many typefaces.

## Logo

The canonical logo system should include:
- wordmark;
- compact mark;
- horizontal lockup;
- monochrome variant;
- reversed variant.

The compact mark should remain recognizable at favicon size.

## Iconography

- 2px visual stroke family;
- rounded joins;
- simple silhouettes;
- no sports chevrons;
- no Figentra cursor.

## Photography

Warm natural light, real people, real spaces, editorial composition.

## Illustration

Minimal line + soft shape compositions with one controlled accent.

## Motion

Slow, calm, intentional:
- 150ms micro-interactions;
- 250ms component transitions;
- 400ms page transitions where justified.

Respect reduced motion.

## Favicon rule

All favicon sizes must derive from the approved compact mark. Do not use the wordmark at tiny sizes.
