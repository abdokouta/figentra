# Public Website Release Gates

Before any brand/site is considered production-ready:

- [ ] Brand charter approved.
- [ ] Legal company/product names verified.
- [ ] Navigation approved.
- [ ] Every route has final copy.
- [ ] Every customer/product claim has evidence.
- [ ] Team profiles have approved names, titles, photos and bios.
- [ ] Canonical logo and favicon sources are established.
- [ ] All required light/dark assets exist.
- [ ] Hero images/illustrations exist for every primary page.
- [ ] OG images exist for every indexable page family.
- [ ] Error pages exist.
- [ ] Security/privacy/terms routes exist.
- [ ] Sitemap and robots policy are generated.
- [ ] Accessibility review passes WCAG 2.2 AA target.
- [ ] Mobile/tablet/desktop review passes.
- [ ] Performance budget passes.
- [ ] Forms and CTAs have working destinations.
- [ ] Analytics and consent behavior are verified.
- [ ] SEO metadata and structured data are verified.
- [ ] No unsupported metrics or customer claims remain.
- [ ] Final visual QA is approved.

A checked documentation gate does not itself prove runtime implementation. Runtime gates must be executed against the deployed site.
