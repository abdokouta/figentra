# Roadmap — Security Kernel

## Sequence

1. Identity provider integration
2. Identity canonical schema
3. Principal model
4. Credential model
5. Service identities
6. M2M OAuth
7. JWT/JWKS
8. Token exchange
9. Delegation/impersonation
10. IAM schema
11. Permission model
12. Policy engine
13. Authorization API
14. Cache/invalidation
15. Tenant
16. Dynamic Scope

Do not start commercial/platform services until this foundation is sufficiently
stable.
