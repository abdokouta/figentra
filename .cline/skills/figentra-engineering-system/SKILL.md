# Figentra Engineering System

The canonical system lives under `docs/engineering-system/`.

## Read first

1. `AGENTS.md`
2. `docs/engineering-system/README.md`
3. `docs/engineering-system/routing.md`
4. `docs/engineering-system/sdlc.md`
5. `docs/engineering-system/quality-gates.md`
6. the relevant platform architecture and implementation plan

## Procedure

1. Classify the request.
2. Identify the authoritative owner.
3. Check boundary impact.
4. Route to the smallest correct specialist set.
5. Create/update the appropriate durable artifacts.
6. Implement only within delegated authority.
7. Verify with applicable quality gates.
8. Report evidence and unresolved findings.

Do not invent a competing architecture, service boundary, agent role, or policy.
